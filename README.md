# TB Gem Helper

> Призматический самоцвет прямо на иконке лота. Аркана Terrorblade на market.dota2.net больше не требует клика по каждому предложению.

Chrome / Яндекс / Edge · Manifest V3 · без API-ключа · без бэкенда · ~30 КБ

![screenshot](docs/screenshot.png)

## Проблема

Аркана Fractal Horns of Inner Abysm стоит по-разному в зависимости от вставленного призматического самоцвета: дефолтный Reflection's Shade — сотни рублей, Vermillion Renewal или Cursed Black — тысячи. В списке лотов маркет показывает только название предмета и цену. Чтобы узнать гем, нужно открыть каждый лот. На странице 65 предложений, страниц — 14.

TB Gem Helper đọcает описание лота и рисует цветной бейдж с названием гема поверх иконки.

## Возможности

- **45 канонических самоцветов** с точными игровыми цветами + русские алиасы официальной локализации.
- **Устойчивый парсер**: склеенные написания (`Чемпионскийзеленый`), `ё`/`е`, апострофы, дефисы, падежные формы, `Legacy (r,g,b)`.
- **Цвет из HTML описания**, а не только из таблицы; нераспознанный гем всё равно показывается (жёлтый пунктир), а не теряется молча.
- **Постоянный кэш** в `chrome.storage.local`: ключ — `classid_instanceid`, поэтому одинаковые гемы не качаются повторно. TTL 90 дней для найденных, 6 ч для пустых, 24 ч для нераспознанных, потолок 8000 записей с вытеснением старых.
- **Пул воркеров 1–3** с ограничением ~3.5 запроса/сек и адаптивным торможением при 429/503/403.
- **Фоновый автопроход страниц**: следующая страница разбирается, пока вы смотрите текущую. Открыли страницу 2 — бейджи уже на месте.
- **Панель управления**: скорость, автопроход, прогресс, легенда гемов с фильтром-подсветкой, экспорт CSV, диагностика.
- **EN / RU** подписи бейджей, экспорт `gem;gem_ru;price;url`.

## Установка

1. Скачайте `TB-Gem-Helper-vX.Y.zip` из [Releases](../../releases) и распакуйте в **постоянную** папку (браузер читает файлы прямо из неё).
2. Откройте `chrome://extensions` (Яндекс: `browser://extensions`).
3. Включите **Режим разработчика**.
4. **Загрузить распакованное расширение** → выберите папку.
5. Откройте market.dota2.net и нажмите Ctrl+F5.

Яндекс Браузер умеет ставить ZIP/CRX перетаскиванием на страницу `browser://tune`.

## Управление

Слева внизу страницы — пилюля с числом бейджей и статусом фона. Клик открывает панель:

| Элемент | Что делает |
|---|---|
| Потоки (1–3) | сколько запросов идёт параллельно |
| Пауза (250–2000 мс) | задержка перед запросом; при росте потоков минимум поднимается автоматически |
| Автопроход страниц | фоновый разбор следующих страниц |
| Вперёд N стр. | глубина автопрохода, 0 = до последней |
| Легенда гемов | клик по чипу гасит все лоты, кроме выбранного гема |
| CSV | выгрузка гем + русское имя + цена + ссылка по текущей странице |
| Диагноз | полный дамп состояния в консоль |

Консольный API:

    __gems.state()          // очередь, фон, кэш, скорость, причина простоя
    __gems.speed('fast')    // slow | normal | fast или speed(2, 600)
    __gems.prefetch(true,0) // автопроход до последней страницы
    __gems.bgNow()          // запустить фон немедленно
    __gems.diag()           // диагностика
    __gems.unknown()        // нераспознанные имена гемов
    __gems.csv()            // выгрузка

## Как это работает

    DOM страницы
      └─ findCards()      ссылки a.item / a[href*="/item/"], картинки-фоны (не <img>)
          └─ очередь      видимые карточки вперёд, остальные следом
              └─ пул      1–3 воркера, пауза + джиттер, brake при 429/503
                  └─ fetch страницы лота → DOMParser → #descr
                      └─ extractGem()  словарь → DOM-сосед → эвристика
                          └─ кэш (classid_instanceid) → бейдж

Фоновый обход сначала пробует понять параметр страницы (`?p=`, `?page=` …), сверяя, что выдача действительно другая. Если сайт игнорирует URL — поднимается скрытый same-origin iframe, который нажимает настоящую кнопку `.page-switcher-r` и читает счётчик «N из M».

### Почему так

- **Ключ кэша — `classid_instanceid`, а не URL лота.** У Dota 2 instanceid кодирует содержимое гнёзд, поэтому десятки лотов с одним гемом дают один запрос.
- **Сравнение имён в «сжатом» виде** (lowercase, `ё→е`, выкинуты пробелы/дефисы/апострофы) вместо сотни ручных дублей: Steam склеивает имя гема с подписью (`Miasmatic GreyPrismatic Gem`).
- **Матч по концу окна перед подписью**, самое длинное совпадение побеждает — иначе лор арканы прилипает к имени гема.
- **Мягкий суффикс только для кириллицы**: сайт пишет «Золото», вики — «Золотой». Проверено на коллизии по всему словарю.
- **Сторож простоя на интервале**, а не сбрасываемый debounce-таймер: чат и лента покупок мутируют DOM каждые пару секунд и не давали таймеру сработать.

## Вежливость к сайту

Расширение не использует API-ключ и не трогает аккаунт: только читает публичные страницы под вашей текущей сессией. Скорость ограничена сверху, при жалобе сервера включается пауза 45 с и снижение темпа, результаты кэшируются на 90 дней. Ничего не отправляется на сторонние серверы — телеметрии нет.

## Разработка

    manifest.json   MV3, permissions: storage, host: market.dota2.net
    content.js      парсер, кэш, пул, автопроход, панель
    styles.css      бейджи и панель

Сборка архива:

    Compress-Archive -Path manifest.json,content.js,styles.css -DestinationPath dist\TB-Gem-Helper.zip

Отладка: `__gems.diag()`; логи каждого найденного гема содержат кликабельную ссылку на лот.
